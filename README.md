# Shadow AI

Shadow AI 是一款专为受限定环境设计的 AI 辅助工具。它旨在提供无窗口、无痕迹的隐蔽运行方式，并通过局域网实现跨设备的 AI
问答交互与控制。

## 核心特性

- **无痕隐蔽运行**：支持在目标设备无前端界面静默运行，避免产生可见的应用程序窗口。
- **局域网跨端协同**：通过同局域网传输，支持使用手机、平板等其他设备进行远程操作。
- **多模型整合**：原生支持接入 Qwen（通义千问）、OpenAI（ChatGPT）、Claude、Gemini、Antigravity 和 Kimi 等主流大语言模型。
- **密钥池并发管理**：支持多账号的 Token 池化配置，支持高并发请求分发，提升响应速度与稳定性。
- **高拓展性接入**：支持快速挂载兼容标准 OpenAI API 接口规范的第三方或自部署 AI 服务。

## 快速开始

1. **服务部署**：在需要辅助的目标设备上运行主程序，此时服务将进入后台进程静默状态。
2. **终端连接**：将操作设备（如移动手机/平板）连入相同局域网网络，通过浏览器访问主服务的局域网 IP 及端口号。
3. **环境配置**：进入控制台页面，完成 API 鉴权配置及偏好模型的设定。
4. **运行交互**：输入文本问题或上传图像，获取 AI 反馈。
